# happy-sad-detector

This is my first Python project created as part of the AIXcelerate training task.
It is a simple program that checks whether a sentence is Happy or Sad using keywords.

## How it works
- Enter a sentence.
- The program checks for happy or sad words.
- It displays the result.

## Sample Output

```text
Enter a sentence: I am happy today
The sentence is Happy
```
